# MERN Product App

## Features
- User Signup (new users can register)
- User Login (JWT based)
- Protected Routes
- Logout functionality
- Product Management (Add, Edit, Delete)

## Notes
- Authentication is implemented using in-memory storage for simplicity.
- Routing and auth flow are fully functional.

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB / In-memory storage

## Run Locally

### Backend
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm run dev
